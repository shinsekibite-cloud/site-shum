Расшифровка архива ПДн

Официальный инструмент YoungPortal для файлов .ypenc (контейнер YPLEA1, AES-256-GCM). Работает в браузере на этом компьютере: ключ и файл никуда не отправляются. проверка сети…

Как пользоваться (для уполномоченного органа)

  1. Получите файл .ypenc и отдельно одноразовый ключ AES (64 hex-символа).
  2. При желании сохраните эту страницу («Сохранить как…») и откройте офлайн.
  3. Выберите файл, вставьте ключ, при необходимости сверьте SHA-256 и отпечаток ключа.
  4. Нажмите «Расшифровать» → скачайте JSON. Дальше можно открыть в любом редакторе или Excel (через конвертер JSON).

7-Zip / WinRAR не откроют этот файл — это не ZIP, а подписанный шифроконтейнер портала. Используйте только этот расшифровщик или CLI node scripts/decrypt-lea.mjs.
