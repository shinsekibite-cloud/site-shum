# Юридический чеклист РФ (операторский) — 2026

Не заменяет консультацию юриста. Актуальный публичный статус модулей отражается в блоках «Актуальные параметры» на `/privacy`, `/rules`, `/terms`.

| Норма / тема | Статус на портале | Действия оператора |
|--------------|-------------------|--------------------|
| **152-ФЗ** ПДн | Политика, согласия при регистрации, версии | Уведомление в РКН при необходимости; ответственный за ПДн в настройках |
| **ч. 5 ст. 18 152-ФЗ** локализация | VPS РФ | Не хранить ПДн граждан РФ за рубежом при сборе через Портал |
| **149-ФЗ** информация | Правила, модерация, жалобы | Сроки реакции на жалобы; сохранять логи модерации |
| **Cookie / метрика** | Баннер, отказ от аналитики | Метрика только после согласия |
| **Пользовательское соглашение** | `/terms` | Не путать с коммерческой офертой |
| **Публичная оферта (ГК)** | Не нужна без платных услуг | При появлении оплаты — отдельный документ с ценой |
| **Реклама (ФЗ-38)** | Нет внешней рекламы | Маркировка при появлении рекламы |
| **Дети (14+)** | Age gate на регистрации | Сохранить; чаты — те же правила |
| **Запрещённый контент** | censor + ContentFlag | Не отключать |
| **Переписка** | DM + чаты клубов/проектов | Право модерации служебных чатов Центра |
| **Капча** | Локальная | Без передачи третьим лицам |
| **TECH / модули** | `/ops`, динамические блоки | Kill-switch меняет «текущий контекст» в политиках без bump версии согласия |

## Сообщения и приглашения (2026-08)

- Личные DM, вкладки клубов/проектов, закрепление/архив (per-user).
- EntityInvite + карточки EVENT/PLACE/ENTITY в DM.
- При отключении `messaging` / режиме тишины — правила переписки не применяются к обычным пользователям.
