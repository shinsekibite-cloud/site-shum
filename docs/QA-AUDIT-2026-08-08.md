**Date:** 2026-08-08

**Environment:** https://young.idivles.ru (VPS `/opt/sochi-portal`)

---

## Assumptions

1. Roles in Prisma enum: `USER`, `PARTICIPANT`, `MODERATOR`, `ADMIN`, `SCANNER`.
2. Moderator fine-grained access via comma-separated `permissions` (see `acl-shared.ts`).
3. `PARTICIPANT` ≈ `USER` for end-user actions (book/apply/join); difference is mostly product/status.
4. `SCANNER` is service account: check-in only, not end-user booking/apply.
5. QA accounts (`RolePass123!`): `qa-admin@sochi.ru`, `mod@sochi.ru`, `user@sochi.ru`, `part@sochi.ru`, `scanner@sochi.ru`.
6. Same host also serves other nginx vhosts (`max`, `rtb`, adult domains) — out of product scope but share RAM/CPU risk.

## 4. Findings by priority

### Critical
| ID | Finding | Status |
|----|---------|--------|
| C1 | Edge ACL existed in `proxy.ts`, but client layout did not enforce per-path permissions (deep-link UX leak) | **Fixed:** admin layout `canAccessAdminPath` + scanner `requirePermissionPage` |
| C2 | Moderator with only `pages` could **review portfolios** via API (`hasPermission(['portfolios','pages'])`) | **Fixed:** portfolios requires `portfolios` only |

### Major
| ID | Finding | Status |
|----|---------|--------|
| M1 | `/admin/scanner`, `/admin/stats`, backup, rkn, moderation, about-team, portfolios pages lacked server `requirePermissionPage` (relied on client + API) | Partially fixed: middleware + scanner server gate; APIs already checked |
| M2 | `RESEND_API_KEY` empty — password reset / email notifications fail in production | Open — needs ops key |
| M3 | 2 GB RAM host shared with other sites — OOM risk on rebuild (documented) | Mitigated: swap+safe-rebuild; recommend 4 GB |
| M4 | SCANNER can call friends/messages APIs — may be unintended for service role | Open — product decision |

## 5. Fixes applied this session

1. Confirmed **`src/proxy.ts`** already gates `/admin` + `/scanner` (Next.js 16 proxy; do not add `middleware.ts` — build conflict).
2. **`api/admin/portfolios`** — require `portfolios` permission (not `pages`).
3. **`acl-shared`** — `/admin/portfolios` maps to `portfolios` only.
4. **`admin/scanner/page.tsx`** — `requirePermissionPage('scanner')`.
5. **`admin/layout.tsx`** — client redirect if path not allowed for moderator permissions.
