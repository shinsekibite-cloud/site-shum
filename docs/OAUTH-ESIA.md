# Вход через Госуслуги (ЕСИА)

Кнопка на `/login` показывается, когда в **Админ → Доступ** включён «Вход через Госуслуги» **и** заданы переменные окружения.

ЕСИА в промышленном контуре обычно требует ГОСТ-сертификат информационной системы. Портал поддерживает стандартный OAuth 2.0 / OIDC-мост (как у многих муниципальных интеграторов). Прямой ГОСТ-клиент Минцифры в Node.js не встроен.

## 1. Переменные на VPS (`.env`, не коммитить)

```
ESIA_CLIENT_ID=
ESIA_CLIENT_SECRET=
# Необязательно, если используете свой шлюз:
ESIA_AUTH_URL=https://esia.gosuslugi.ru/aas/oauth2/ac
ESIA_TOKEN_URL=https://esia.gosuslugi.ru/aas/oauth2/te
ESIA_USERINFO_URL=https://esia.gosuslugi.ru/rs/prns
ESIA_ISSUER=https://esia.gosuslugi.ru
ESIA_SCOPE=openid fullname email mobile
```

Callback NextAuth: `https://<домен>/api/auth/callback/esia`

Для теста (`ty.idivles.ru`) зарегистрируйте отдельный redirect URI.

## 2. Включение

1. Прописать секреты в `.env` **и** перезапустить web.
2. Админ → Доступ → «Вход через Госуслуги (ЕСИА)».
3. На `/login` появится кнопка «Войти через Госуслуги».

Если тумблер включён, а env пустой, кнопка неактивна (подсказка «не настроено»).

## 3. Согласия 152-ФЗ

Первый вход через ЕСИА создаёт `User` через Prisma Adapter. Недостающие поля (телефон, дата рождения 14+) пользователь дополняет в кабинете; политика и правила — те же, что при регистрации.

## 4. Выключение

Снять тумблер в админке. Существующие связанные `Account.provider = esia` сохраняются; кнопка скрывается.
