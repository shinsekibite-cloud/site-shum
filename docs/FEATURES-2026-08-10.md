# Обновления 2026-08-10 — immersive, эко, уведомления, боты

## Как работает Admin immersive и TECH

1. **Immersive** — на `/admin`, `/ops`, `/scanner` `StaffChrome` ставит `body.is-admin`. CSS скрывает публичный `.glass-nav`, футер и bottom-nav. Админка рисует свой сайдбар.
2. **Колокольчик** — в immersive публичный навбар скрыт, поэтому `NotificationsBell` встроен в сайдбар админки и в шапку `/ops`.
3. **TECH** — env `TECH_EMAIL` + `TECH_BOOTSTRAP_PASSWORD` (или hash). Логин на `/login` создаёт/назначает роль `TECH`, доступ только к `/ops` (не `/admin`). Подробнее: `ADMIN.md`.
