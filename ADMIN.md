# Администрирование

## Доступ администратора

Учётные данные **не хранятся в репозитории**.

### Production
- Email: `admin@sochi.ru`
- Пароль: только в секретном хранилище / менеджере паролей команды
- Роль: `ADMIN`

При компрометации репозитория или утечке пароля — немедленно сменить пароль через `/admin/users` или сброс в БД.

### Staging / QA
- Email: `qa-admin@sochi.ru` (отдельный админ для тестов)
- Пароль: задаётся env `QA_SEED_PASSWORD` или `STAGING_ADMIN_PASS` при запуске `scripts/seed-qa-fill.mjs`
- Дополнительно: `mod@sochi.ru`, `user@sochi.ru`, `part@sochi.ru`, `scanner@sochi.ru`

**Важно:** seed **не перезаписывает** пароль существующих пользователей и **не трогает** пароль prod `admin@sochi.ru`.

### TECH (техслужба) — `/ops`

Роль `TECH` — отдельная учётка для kill-switch модулей и техфлагов. **Не** открывает `/admin` (редирект на `/ops`).

1. В env задайте `TECH_EMAIL` и `TECH_BOOTSTRAP_PASSWORD` (или `TECH_PASSWORD_HASH`).
2. Войдите на `/login` этим email/паролем — при первом входе учётка создаётся с ролью `TECH`.
3. Откроется `/ops` (модули, maintenance). Публичный header сайта скрыт (immersive).

Подробнее: `docs/OPS-TECH.md`, обучение: `docs/LEARNING_BOOK.md`.

### Immersive админка (без site header)

На маршрутах `/admin`, `/ops`, `/scanner` компонент `StaffChrome` ставит `body.is-admin`. CSS скрывает `.glass-nav`, футер и нижнюю навигацию. Колокольчик уведомлений доступен в сайдбаре админки / верхней панели ops.

### Фраза восстановления (24 слова)

В личном кабинете → профиль → блок «Фраза восстановления» можно создать офлайн-фразу из 24 русских слов (как в криптокошельке). Сброс пароля по фразе: `/forgot-password` → вкладка «24 слова».

## Админ-разделы

- /admin/programs — гранты / добро / самоуправление
- /admin/projects — проекты
- /admin/clubs — клубы
- /admin/spaces — пространства
- /admin/bookings — бронирования
- /admin/applications — заявки
- /admin/users — пользователи и роли
- /admin/pages — статические страницы
- /admin/settings — SMTP, контакты, VK, настройки бронирования
- /admin/bots — Telegram / MAX
- /ops — TECH kill-switches

## Rate limit / Redis

При наличии `REDIS_URL` (в docker-compose по умолчанию `redis://redis:6379`) лимиты логина, регистрации, заявок, сообщений и бронирований шарятся между инстансами `web`. Без Redis используется in-memory fallback.

## Быстрый доступ

- ПК: `?` — справка по клавишам; `G` затем буква (H/E/P/D/A…); `/` — поиск
- Телефон: кнопка ⚡ справа внизу — панель быстрого доступа (свайпы с края убраны — конфликтовали с браузером)
- Инструктаж и шпаргалка также в профиле → «Инструкции»

## Полезные API (под авторизацией ADMIN)

- /api/admin/demo-seed — наполнить демо-данными
- /api/admin/demo-clear — очистить демо-данные
- /api/admin/export — экспорт
