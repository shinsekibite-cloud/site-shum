# Changelog — YoungPortal

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).  
Версия в футере и в `package.json` / `src/lib/app-version.ts` должны совпадать.  
Каждый пользовательский релиз на ty → запись здесь + bump версии **до** staging deploy.

## [1.5.14] — 2026-08-18

### Fixed
- Дашборд: запросы к выключенным модулям (сообщения, вакансии, афиша, достижения…) больше не стреляют в API с ответом 503; неожиданный 503/502/504 показывает тост, а не только ошибку в консоли
- Профиль: ссылка «Магазин» вынесена из `<summary>` (доступность HTML5 / скринридеры)

### Changed
- Тяжёлые панели кабинета (магазин, портфолио, витрина, настройки, игры) подключаются через `next/dynamic`, чтобы CSS/JS соседних вкладок не грузились сразу на overview/settings/showcase. Оставшиеся предупреждения preload общего `_next/static/css` — нормальное поведение production-сборки Next (стили из `globals.css` уже на странице)



### Added
- Главная: фон строго по выбору администратора (видео / фото); при видео картинка остаётся постером и fallback, если ролик не загрузился за 8 с
- Вход и регистрация: ссылка «На главную»
- После регистрации аккаунт в статусе «Гость» (на модерации): кабинет и просмотр сайта есть, бронь/запись/заявки — нет, пока админ не одобрит или не пройдут 3 рабочих часа (пн–пт 09:00–18:00 МСК)
- Админка «Заявки регистрации»: очередь аккаунтов (одобрить / заблокировать)

### Fixed
- Мобильная шапка: название «Молодёжь Сочи» видно рядом с логотипом и не перекрывает поиск, вход и меню

### Changed
- Блокировка пользователя в карточке по-прежнему доступна в любой момент, в том числе после одобрения
